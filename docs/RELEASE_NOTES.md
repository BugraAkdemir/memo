## Installation

### Windows
Download `Memo-Setup-v$VERSION.exe` and run the installer. The setup wizard will guide you through installation.

### Linux
- **AppImage**: Download `Memo-linux-x64-v$VERSION.AppImage`, make executable (`chmod +x`), and run.
- **tar.gz**: Extract and run `./run_memo.sh`.

### First Run
1. Start the application
2. Complete the setup wizard (select language, persona)
3. Download a model or connect an external provider (OpenAI, Claude, etc.)
4. Start chatting!

## System Requirements
- **OS**: Windows 10+, Ubuntu 22.04+ / similar Linux distro
- **RAM**: 8GB+ (16GB+ recommended for local models)
- **GPU**: Optional (NVIDIA CUDA / AMD ROCm for GPU acceleration)
- **Storage**: 500MB + model files (GGUF files are 2-15GB)
