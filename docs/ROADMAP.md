# Memo Roadmap (V2.0 & Beyond)

The strategic vision for the future of the Memo AI Memory Shell.

## Phase 1: Performance & Stability (Current)
- [x] Decoupled Go/Flutter architecture.
- [x] Atomic GOB persistence.
- [x] Basic RAG implementation.
- [x] Multi-process Llama management.

## Phase 2: Enhanced Intelligence (Upcoming)
- [ ] **Dynamic Top-K Selection:** Automatically adjust memory retrieval based on query complexity.
- [ ] **Cross-Session Reasoning:** Better synthesis of information spread across multiple chat sessions.
- [ ] **Knowledge Graph Integration:** Visualizing semantic links between memories in a graph view (Obsidian-style).
- [ ] **Advanced Reranking:** Use a secondary model to rerank retrieved memories for even higher accuracy.

## Phase 3: Ecosystem & Integration
- [ ] **Plugin System:** Allow developers to write Go plugins for custom tools (Web search, Calculator, Python exec).
- [ ] **Mobile Companion App:** Access your local memory via a secure tunnel on your phone.
- [ ] **Import/Export Wizards:** One-click import from Notion, Obsidian, or Google Keep.

## Phase 4: Full Autonomy
- [ ] **Autonomous Memory Pruning:** AI-driven cleanup of redundant or contradictory memories.
- [ ] **Self-Improving System Prompt:** The assistant learns and suggests improvements to its own persona based on user feedback.
