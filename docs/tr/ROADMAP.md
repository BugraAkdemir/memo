# Memo Yol Haritası (V2.0 ve Ötesi)

Memo Yapay Zeka Hafıza Kabuğu'nun geleceği için stratejik vizyon.

## Aşama 1: Performans ve Kararlılık (Mevcut)
- [x] Ayrıştırılmış (Decoupled) Go/Flutter mimarisi.
- [x] Atomik GOB kalıcılığı.
- [x] Temel RAG uygulaması.
- [x] Çoklu süreç (multi-process) Llama yönetimi.

## Aşama 2: Gelişmiş Zeka (Gelecek)
- [ ] **Dinamik Top-K Seçimi:** Sorgu karmaşıklığına göre hafıza geri getirme miktarını otomatik ayarla.
- [ ] **Oturumlar Arası Akıl Yürütme:** Birden fazla sohbet oturumuna yayılmış bilgilerin daha iyi sentezlenmesi.
- [ ] **Bilgi Grafiği (Knowledge Graph) Entegrasyonu:** Anılar arasındaki anlamsal bağlantıların grafik görünümünde (Obsidian tarzı) görselleştirilmesi.
- [ ] **Gelişmiş Yeniden Sıralama (Reranking):** Geri getirilen anıları daha yüksek doğruluk için yeniden sıralamak üzere ikincil bir model kullanın.

## Aşama 3: Ekosistem ve Entegrasyon
- [ ] **Eklenti Sistemi:** Geliştiricilerin özel araçlar (Web araması, Hesap makinesi, Python çalıştırma) için Go eklentileri yazmasına olanak tanı.
- [ ] **Mobil Yardımcı Uygulama:** Yerel hafızanıza telefonunuzdan güvenli bir tünel üzerinden erişin.
- [ ] **İçe/Dışa Aktarma Sihirbazları:** Notion, Obsidian veya Google Keep'ten tek tıkla içe aktarma.

## Aşama 4: Tam Otonomi
- [ ] **Otonom Hafıza Budama:** Gereksiz veya çelişkili anıların yapay zeka tarafından temizlenmesi.
- [ ] **Kendi Kendini Geliştiren Sistem Prompt'u:** Asistan, kullanıcı geri bildirimlerine göre kendi kişiliği için iyileştirmeler öğrenir ve önerir.
