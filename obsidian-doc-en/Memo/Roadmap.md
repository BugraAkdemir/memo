# Roadmap — Strategic Plan

Full detail: `docs/ROADMAP.md`.

---

## v3.1.0 — ✅ Current Release

**Theme**: Foundation Expansion
- WhatsApp integration (QR pairing, messaging, agent tools)
- External provider system (7 providers, router, fallback)
- Agent mode (8 tools, permission system, sandbox)
- Orchestra mode (multi-model orchestration, 8 roles)
- Mobile companion app (basic)
- Backup & restore system (`.memo` format, Google Drive)
- Remote access (ngrok)
- 61 bug fixes
