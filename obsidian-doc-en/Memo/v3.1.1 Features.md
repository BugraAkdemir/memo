# v3.1.1 Features

Major new capabilities added in the v3.1.0-beta release.

---

## 🆕 New in v3.1.0

### 1. WhatsApp Integration
- QR code pairing with WhatsApp Web multi-device protocol
- Bidirectional messaging with contact name resolution
- Whitelist-based file transfer
- 4 agent tools: `SendWhatsApp`, `SearchWhatsApp`, `LatestWhatsAppChats`, `GetWhatsAppMessages`
- Local SQLite storage isolated from main memory store
- See [[WhatsApp Integration]] for full details

### 2. External Provider System
- Full rewrite of `internal/provider/` package
- Support for **7 providers**: OpenAI, Google Gemini, xAI Grok, Anthropic Claude, OpenRouter, Groq, Ollama
- Unified `Provider` interface with `ChatCompletion`, `ChatCompletionStream`, `ListModels`
- Router with automatic fallback chain — on failure, tries next provider; auto-disables after 3 consecutive failures
- Health check goroutine periodically re-enables disabled providers
- AES-256-GCM encrypted API key storage
- See [[External Providers]] for full details

### 3. Agent Mode (Tool Calling)
- 8 built-in tools: `read_file`, `write_file`, `delete_file`, `list_directory`, `run_command`, `search_files`, `get_file_info`, `read_env`
- Three-tier danger level system: Safe, Medium, Dangerous
- 6 permission policies: PromptAlways, AllowOnce, AllowSession, AllowForever, DenyOnce, DenyForever
- Execution sandbox with path validation, command blacklist (23 patterns), rate limiting (30 calls/min)
- Audit trail (last 1000 entries in memory)
- See [[Agent Mode]] for full details

### 4. Orchestra Mode (Multi-Model)
- Conductor pattern: Plan → Execute → Synthesize three-phase workflow
- 8 built-in expert roles: Planner, Frontend, Backend, Bug Fixer, Reviewer, Security, DevOps, General
- Parallel task execution for independent tasks, sequential for dependant tasks
- Retry with exponential backoff
- SSE streaming for real-time progress updates
- See [[Orchestra Mode]] for full details

### 5. Mobile Companion App
- Thin Flutter client for Android/iOS
- Connects via LAN IP or ngrok tunnel
- Token-based authentication
- Streaming chat (SSE), Markdown rendering
- Session management, provider toggle, model start/stop
- See [[Mobile App]] for full details

### 6. Backup & Restore System
- `.memo` zip format for full export/import
- Includes sessions, config, providers, orchestra, memory, WhatsApp
- Wipe endpoint for complete data erasure
- Google Drive E2E encrypted cloud sync
- See [[Backup & Restore]] for full details

### 7. Remote Access (ngrok)
- Built-in ngrok integration for secure tunneling
- Token authentication (`X-Memo-Token`)
- Auto-start/stop via settings
- See [[Remote Access (ngrok)]] for full details

### 8. Bug Fixes & Reliability
- 61 documented bug fixes (see [[Resolved Issues]])
- Data race fixes across all shared state (`a.client`, `a.syncManager`, `a.store`, incognito toggle)
- SSE goroutine leak fixes, context propagation through LLM call chain
- Security: path traversal fixes, config file permissions, zip bomb protection
- Flutter: animation performance, memory leaks, error handling improvements

### 9. Multi-Modal Enhancements
- Cross-mode: external provider chat + local embedding simultaneously
- Improved STT with proper process group cleanup
- Better GPU detection with AMD lspci support

### 10. Documentation Overhaul
- Full EN/TR documentation in `docs/` and Obsidian vault
- ROADMAP.md with strategic plan through v3.5.0
- FEATURES.md comprehensive catalog
- KNOWN_ISSUES.md, RESOLVED_ISSUES.md exhaustive bug audit
- TECHNICAL_DEEP_DIVE.md, TROUBLESHOOTING.md, CONTRIBUTING.md
- Turkish README, architecture docs, and Obsidian vault
