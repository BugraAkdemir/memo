# v3.1.0 Özellikleri

v3.1.0-beta sürümünde eklenen büyük yeni yetenekler.

---

## 🆕 v3.1.0'da Yeni

### 1. WhatsApp Entegrasyonu
- WhatsApp Web multi-device protokolü ile QR kod eşleştirme
- Kişi adı çözümlemeli çift yönlü mesajlaşma
- Beyaz liste tabanlı dosya transferi
- 4 agent aracı: `SendWhatsApp`, `SearchWhatsApp`, `LatestWhatsAppChats`, `GetWhatsAppMessages`
- Ana hafıza deposundan izole yerel SQLite depolama
- Detay: [[WhatsApp Entegrasyonu]]

### 2. Harici Sağlayıcı Sistemi
- `internal/provider/` paketinin tamamen yeniden yazımı
- **7 sağlayıcı desteği**: OpenAI, Google Gemini, xAI Grok, Anthropic Claude, OpenRouter, Groq, Ollama
- Ortak `Provider` arayüzü: `ChatCompletion`, `ChatCompletionStream`, `ListModels`
- Otomatik fallback zinciri ile Router — hata durumunda bir sonraki sağlayıcıya geçer; 3 ardışık hatada otomatik devre dışı bırakır
- Sağlık kontrolü goroutine'i ile devre dışı sağlayıcıları periyodik olarak test eder
- AES-256-GCM şifreli API anahtarı depolama
- Detay: [[Harici Sağlayıcılar]]

### 3. Ajan Modu (Tool Calling)
- 8 yerleşik araç: `read_file`, `write_file`, `delete_file`, `list_directory`, `run_command`, `search_files`, `get_file_info`, `read_env`
- Üç seviyeli tehlike sistemi: Güvenli, Orta, Tehlikeli
- 6 izin politikası: PromptAlways, AllowOnce, AllowSession, AllowForever, DenyOnce, DenyForever
- Yürütme sandbox'ı: yol doğrulama, komut kara listesi (23 desen), hız sınırlaması (30 çağrı/dk)
- Denetim izi (bellekte son 1000 kayıt)
- Detay: [[Ajan Modu]]

### 4. Orkestra Modu (Multi-Model)
- Conductor deseni: Planla → Yürüt → Sentezle üç aşamalı iş akışı
- 8 yerleşik uzman rolü: Planlayıcı, Frontend, Backend, Hata Düzeltici, İncelemeci, Güvenlik, DevOps, Genel
- Bağımsız görevler için paralel, bağımlı görevler için sıralı yürütme
- Üstel geri bildirim ile yeniden deneme
- Gerçek zamanlı ilerleme güncellemeleri için SSE akışı
- Detay: [[Orkestra Modu]]

### 5. Mobil Eşlikçi Uygulama
- Android/iOS için ince Flutter istemci
- LAN IP veya ngrok tüneli ile bağlantı
- Token tabanlı kimlik doğrulama
- Akışlı sohbet (SSE), Markdown işleme
- Oturum yönetimi, sağlayıcı açma/kapama, model başlatma/durdurma
- Detay: [[Mobil Uygulama]]

### 5b. Proaktif Öğrenme: Niyet Çıkarımı + Takvim
- **Niyet çıkarımı** — normal sohbette ve WhatsApp'ta (gelen + giden) plan/alışkanlık beyanlarını anlama
- İki aşamalı işleme: hızlı anahtar kelime ön filtresi → LLM çıkarımı (sıradan mesaj LLM çağırmaz)
- **Sadece özet saklama** — ham mesaj metni asla kaydedilmez (gizlilik-öncelikli)
- **Takvim sistemi** — tespit edilen etkinlikler otomatik eklenir, etkinlik öncesi telefona hatırlatma (10dk–2sa, ayarlanabilir)
- Mobil uygulamada aylık takvim sekmesi + yerel bildirimler
- **Tek model modu** — öğrenme kararları için Orchestra yerine seçilen tek model
- `internal/intent/` + `internal/calendar/` paketleri, `/api/calendar/*` ve `/api/learning/settings` uçları
- Detay: [[Proaktif Öğrenme ve Takvim]]

### 6. Yedekleme & Restore Sistemi
- Tam dışa/içe aktarma için `.memo` zip formatı
- Oturumlar, yapılandırma, sağlayıcılar, orkestra, hafıza, WhatsApp dahil
- Tam veri silme için wipe endpoint'i
- Google Drive E2E şifreli bulut senkronizasyonu
- Detay: [[Yedekleme & Restore]]

### 7. Uzaktan Erişim (ngrok)
- Güvenli tünel için yerleşik ngrok entegrasyonu
- Token kimlik doğrulama (`X-Memo-Token`)
- Ayarlardan otomatik başlatma/durdurma
- Detay: [[Uzaktan Erişim (ngrok)]]

### 8. Hata Düzeltmeleri ve Güvenilirlik
- 61 belgelenmiş hata düzeltmesi (bkz: [[Çözülen Sorunlar]])
- Tüm paylaşılan durumda veri yarışı düzeltmeleri (`a.client`, `a.syncManager`, `a.store`, incognito)
- SSE goroutine sızıntı düzeltmeleri, LLM çağrı zinciri boyunca context yayılımı
- Güvenlik: path traversal düzeltmeleri, config dosyası izinleri, zip bomb koruması
- Flutter: animasyon performansı, bellek sızıntıları, hata yönetimi iyileştirmeleri

### 9. Çoklu Modalite Geliştirmeleri
- Cross-mode: harici sağlayıcı sohbeti + yerel embedding eşzamanlı
- Düzgün süreç grubu temizliği ile geliştirilmiş STT
- AMD lspci desteği ile daha iyi GPU algılama
