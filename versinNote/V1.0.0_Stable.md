# Memo V1.0.0 Stable Linux Release Notes

Memo (Local LLM Memory) has reached its V1.0.0 Stable release as a fully revamped, portable, and high-performance desktop application! This version marks the transition from the web-based Svelte interface to a completely native Flutter Desktop UI, alongside massive architectural improvements in the backend.

## 🚀 Key Features & Highlights

### 1. All-New Flutter Desktop Interface
- The old Svelte WebView (Wails) architecture has been completely abandoned, replaced by a native Flutter Desktop interface that is much faster, fluid, and consumes significantly fewer resources.
- A brand new modern, sleek, and dark-focused design tailored with an easy-on-the-eyes "Cream/Gold" color palette.
- Features a navigation panel, smooth animations, and a rich markdown-supported chat screen.

### 2. Standalone (Headless) Go Server Architecture
- Backend operations have been completely decoupled from Wails, transforming into a standalone (headless) Go REST API server.
- This allows the frontend (Flutter) and backend (Go) to communicate independently in a secure and flexible manner.

### 3. Universal Linux Distribution (Portable)
- The application can now run anywhere with a single click!
- Distribution formats: `.AppImage`, `.tar.gz`, and `.deb`.
- Overcoming read-only filesystem limitations, the app securely creates its own workspace directory directly in the user's home folder at `~/.memo/` (for logs, models, and dependencies).
- `llama.cpp` shared libraries (libllama, libggml) are automatically bundled, entirely eliminating the hassle of manual dependency installations for users.

### 4. Advanced Model Management (Model Store)
- **HuggingFace Integration:** Added the ability to search for models on HuggingFace directly from within the app, view `.gguf` files, and download them with a single click.
- **Import Local Models:** Easily import existing `.gguf` files already on your computer directly into Memo using the "Import" button.
- **Dynamic Resource Management:** Dynamically configure Context Size, GPU Layers, and Port settings via the UI when launching models.

### 5. Memory and Configuration
- Simultaneously manage both the main language model and the memory (embedding) model, tracking their statuses (running/stopped) in real-time.
- Comprehensive management of system prompts and incognito prompts.

## 🛠️ Technical Improvements & Fixes
- Enhanced stability by resolving crashes and context errors caused by the STT (Speech-to-Text) Python services.
- Achieved full feature parity in the migration to Flutter; all Svelte interface functions (settings menus, chats, etc.) are successfully implemented.
- Resolved TLS (self-signed) issues at the network protocol level, stabilizing local API communication.
- Removed large `.gguf` files and bin folders from Git tracking to optimize distribution sizes (Clean `.gitignore`).

With Memo V1.0.0 Stable, a completely local, privacy-focused AI experience with direct installation and zero external dependencies (like LM Studio) awaits you!
