# Memo V3.0.0 Release Notes: Smarter, More Powerful, and Completely Under Your Control!

Welcome to Memo V3.0.0! This massive update transforms Memo from a simple chat assistant into a full-fledged AI agent and multi-model orchestration platform. Here are the amazing features waiting for you in the new version:

## 🌟 Highlighted Features

### 🤖 AI Agent Mode: Interact with Your Computer
Memo no longer just answers your questions—it can get things done! With the new Agent Mode, Memo can (with your permission) read and edit files, run terminal commands, and analyze your projects. Security is our priority: you will be prompted to approve any critical actions.

### 🎼 Orchestra Mode: The Power of Teamwork
Instead of giving a difficult task to a single model, use Orchestra Mode! A "Chief" model plans the task and divides it into sub-tasks. Then, "Specialist" models (Frontend, Backend, DevOps, etc.) solve their respective parts. Finally, the Chief synthesizes all results into a perfect answer. You can now even run Orchestra and Agent modes simultaneously to turn complex plans into immediate action!

### 🌍 External Provider Support (OpenRouter, OpenAI, Claude, Gemini...)
In addition to the power of local models (llama.cpp), you can now connect to external providers like OpenAI (GPT-4o), Anthropic (Claude), Google (Gemini), xAI (Grok), and OpenRouter. Your API keys are stored securely on your device, encrypted with military-grade AES-256-GCM. With our new OpenRouter model browser, you can view pricing and context limits for all models directly within the app.

### 🎨 Dark Mode and UI Enhancements
The highly anticipated Dark Mode is finally here! Switch your theme from Settings to reduce eye strain during late-night coding sessions. We've also made the chat interface significantly smoother and completely eliminated scrolling jank.

### 💬 Enhanced Chat Experience
- **Smart Titles:** Chats are no longer saved as "hello". Memo automatically generates short, context-aware titles using AI.
- **Edit & Delete Messages:** Easily edit a prompt if you made a typo, or delete unnecessary messages from the history.
- **Chat Management:** Rename or delete your past chat sessions with a simple right-click.
- **Stop Generation:** Stop the AI mid-sentence by pressing the Stop button to save time and resources.
- **Markdown in User Messages:** Your code blocks and markdown formatting now render perfectly in your own chat bubbles!
- **Advanced Slash (/) Commands:** A brand new, instantly filtered command menu that you can navigate using your keyboard.

### ⚙️ You Are in Control
- **Memory Toggle:** Turn off RAG (Retrieval-Augmented Generation) with a single click when you don't need it, preventing the model from filling up its context limit.
- **Model Parameters UI:** Adjust Temperature, Top P, and Context Size directly from the interface to control the model's creativity and memory limits.
- **Streaming Toggle:** Don't want to see responses generated token-by-token? Turn off streaming to see the full response all at once.

## 🛠️ Performance & Security Under the Hood
- Eliminated UI frame drops during heavy chat sessions for a buttery-smooth experience.
- Reduced RAM usage by 50% during memory indexing.
- Improved connection stability, auto-retry mechanisms, and Rate Limit protections.
