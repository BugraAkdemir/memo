# Memo V2.0.0 — Release Notes

**"Bundled Engine & GPU Mode Control"**

Memo V2.0.0, uygulamanın temel motor mimarisini köklü biçimde değiştiren bir **Major Release**'tir. İnternet bağımlılığı olan "indir-ve-kur" sistemi terk edilerek, tüm donanım varyasyonlarını (CPU / NVIDIA / AMD) paket içinde taşıyan **Tak-Çalıştır (Bundled Engine)** mimarisine geçilmiştir. Kullanıcı artık uygulamayı ilk açtığı andan itibaren — internet olmadan — yapay zeka motoru hazırdır.

---

## 🏗️ Mimari Değişiklik: Bundled Llama Engine

> V1.5.0'daki **download-on-demand** modeli tamamen terk edildi.

### Eski Sistem (V1.5.0)
- İlk çalıştırmada GitHub'dan llama.cpp binary indiriliyordu.
- İnternet hızı, GitHub erişimi veya kütüphane bağlama (symlink) hataları kritik sorunlara yol açıyordu.
- CPU-only binary gömülüydü; GPU desteği ek indirme gerektiriyordu.

### Yeni Sistem (V2.0.0)
- Uygulama paketi içinde **3 ayrı engine seti** (CPU, NVIDIA/CUDA, AMD/ROCm) gömülü olarak dağıtılır:
  ```
  binaries/
  ├── linux/
  │   ├── cpu/llama-server
  │   ├── nvidia/llama-server
  │   └── amd/llama-server
  └── windows/
      ├── cpu/llama-server.exe
      ├── nvidia/llama-server.exe
      └── amd/llama-server.exe
  ```
- **%100 Offline Çalışma:** İlk kurulumdan itibaren internet gerekmez.
- **Garantili Uyumluluk:** Her platform için test edilmiş binary'ler gömüldüğü için "bende çalışmadı" senaryoları minimize edilir.
- **Uygulama Boyutu Artışı:** Paket boyutu ~100 MB'tan ~700 MB – 1 GB arasına çıkmıştır. Bu bilinçli bir takas kararıdır.

## 🚀 Öne Çıkan Yenilikler

### 1. Motor Modu Seçimi (Engine Mode) — Yeni UI
*   **Ayarlar → Llama** sekmesine **"Motor Modu"** dropdown menüsü eklendi.
*   Kullanılabilir modlar:
    | Mod | Davranış |
    |-----|----------|
    | **Otomatik (Önerilen)** | Sistem donanımını algılayarak en uygun binary'yi seçer. |
    | **Sadece İşlemci (CPU)** | GPU katmanlarını sıfırlar, CPU-only binary kullanır. |
    | **NVIDIA (CUDA)** | CUDA destekli NVIDIA binary'sini zorlar. |
    | **AMD (ROCm/Vulkan)** | ROCm/Vulkan destekli AMD binary'sini zorlar. |
*   Mod değişikliği anında backend'e `PUT /api/models/config` ile iletilir ve `config.yaml` dosyasına kalıcı olarak yazılır.
*   Çalışan embedding sunucusu otomatik olarak durdurulup yeni modla yeniden başlatılır — kullanıcının uygulamayı kapatıp açmasına gerek yoktur.

### 2. Yeni Config API Endpoint'leri
*   `GET /api/models/config` — Mevcut Llama yapılandırmasını (engine_mode, binary_path, port vb.) döner.
*   `PUT /api/models/config` — Motor modunu ve diğer Llama ayarlarını günceller.
*   Backend'de `UpdateLlamaConfig()` bridge fonksiyonu eklendi; config değişikliklerini atomik olarak diske yazar.

### 3. Senkron Model Yükleme (Synchronous StartLocalModel)
*   **Eski davranış (V1.5.0):** `StartLocalModel` fire-and-forget goroutine ile çalışıyordu. Flutter event sistemi devre dışı olduğu için model yükleme durumu (loading/ready/error) UI'a hiç ulaşmıyordu — sessiz hatalar oluşuyordu.
*   **Yeni davranış (V2.0.0):** Model yükleme artık **senkron** çalışır. HTTP isteği, model hazır olana kadar (maks. 3 dk) bloklanır. Başarı ya da hata doğrudan HTTP yanıtıyla döner.
*   UI artık model yükleme durumunu güvenilir biçimde gösterebilir: başarılı ise çalışır, hata ise kullanıcıya anlamlı Türkçe hata mesajı döner.

### 4. Geliştirilmiş Model Mağazası (Model Store) UI
*   **HuggingFace Arama Kartları** tamamen yeniden tasarlandı:
    - Beğeni sayısı, etiketler (tags), ve indirme sayısı görsel olarak zenginleştirildi.
    - Gradient arka planlar, gölgeler (`shadowMd`) ve hover efektleri eklendi.
    - "Dosyaları Gör" butonu "Dosyaları İncele" olarak güncellendi, ikonlar modernleştirildi.
*   **İndirme İlerleme Kartı** baştan yazıldı:
    - İndirilen/toplam boyut formatı (`_formatBytes`) eklendi: `1.2 GB / 4.7 GB` gibi okunabilir çıktı.
    - Gradient arka plan, büyük ikon, ve belirgin dosya adı ile premium bir görünüm kazandı.
    - İndirme tamamlandığında yerel model listesi otomatik olarak yenilenir (`ref.invalidate(localModelsProvider)`).
*   **Motor Kontrolü Entegrasyonu:** Yerel model "Başlat" butonu, Llama motoru kurulu değilse otomatik olarak devre dışı kalır (`!installed ? null : onPressed`). Kullanıcı önce motoru kurmalıdır.

### 5. Sistem Donanım Durumu Paneli
*   Ayarlar → Llama ekranına **"Sistem Donanım Durumu"** bilgi kartı eklendi.
*   Algılanan GPU adı ve tipi gerçek zamanlı gösterilir.
*   GPU algılanmadıysa "Sadece İşlemci (CPU) algılandı" uyarısı verilir.

## 🛠️ Teknik İyileştirmeler & Altyapı

### Binary Çözümleme Motoru (`resolveBinary`) — Tamamen Yeniden Yazıldı
*   Öncelik sırası artık şu şekildedir:
    1. Seçilen mod (`binaries/{os}/{mode}/llama-server`) — doğrudan hedef.
    2. Yapılandırılmış yol (`config.yaml → binary_path`).
    3. Bundled otomatik tarama: `amd → nvidia → cpu → bin/` sırasıyla aranır.
    4. Sistem PATH'i (`exec.LookPath`).
*   Bundled binary algılandığında dinamik GPU kontrolü atlanır — binary'nin uyumluluğu paketleyicinin sorumluluğundadır.

### Installer Geliştirmeleri (`installer.go`)
*   **Mimari farkındalık:** Asset seçiminde `GOARCH` (`x64`) filtresi eklendi. Yanlış mimariye ait binary indirilmesi engellendi.
*   **Fallback zinciri genişletildi:** Platform + mimari + GPU tercihi → platform + mimari → platform (son çare).
*   **Symlink desteği:** `.tar.gz` arşivlerinden çıkarma sırasında sembolik bağlantılar artık doğru işlenir (özellikle `libllama.so → libllama.so.xxxx` zinciri).

### Embedding Sunucu Yönetimi
*   Embedding sunucusu başlatılmadan önce mevcut çalışan instance otomatik olarak durdurulur. Port çakışması önlenir.
*   `WaitReady` timeout'u 60 saniyeden **120 saniyeye** çıkarıldı (büyük embedding modelleri için).
*   `--pooling mean` parametresi kaldırıldı — llama.cpp'nin varsayılan davranışına güvenilir.

### Config Yapısı (`config.yaml` / `config.go`)
*   Yeni alan: `engine_mode` (varsayılan: `"auto"`) — `"auto"`, `"cpu"`, `"nvidia"`, `"amd"` değerlerini alır.
*   `binary_path` artık varsayılan olarak boş bırakılır — bundled sistem otomatik çözümleme yapar.
*   Yeni alan: `max_history` — sohbet geçmişi uzunluk kontrolü için (varsayılan: 20).

### Paketleme Scriptleri — Yeniden Yapılandırıldı
*   **`package_linux.sh`** ve **`package_windows.sh`**: `data/bin/` yerine `binaries/{platform}/` dizininden kopyalama yapar.
*   **`build_releases.sh`**: İlk çalıştırma mantığı `data/bin/llama-server` yerine `binaries/` dizini kontrolüne güncellendi. AppImage, .deb ve .tar.gz paketleri yeni yapıyı doğru taşır.
*   **[YENİ] `download_binaries.sh`**: Geliştirici kolaylığı için tüm platform binary'lerini tek komutla GitHub'dan indiren otomasyon scripti eklendi.
*   Engine binary'lerine `chmod +x` otomatik uygulanır.

### Hata Mesajları (UX)
*   Llama binary bulunamadığında kullanıcıya anlamlı Türkçe hata mesajı döner:
    > *"Llama.cpp motoru (llama-server) bulunamadı. Lütfen motorun kurulu olduğundan emin olun veya Ayarlar → Llama kısmından yolu kontrol edin."*
*   Model yükleme timeout'unda:
    > *"Model yükleme zaman aşımına uğradı (3 dk)."*

## 📋 Bilinen Sorunlar Belgesi — Kapsamlı Güncelleme

`docs/KNOWN_ISSUES.md` baştan yazılarak genişletildi. Yeni eklenen kategoriler ve risk detayları:

| Kategori | Yeni/Güncellenen Maddeler |
|----------|---------------------------|
| **Eşzamanlılık** | `saveMemoryAsync` goroutine'inin `storeMu` ile yarış riski detaylandırıldı. |
| **Performans** | Etkileşim başına ayrı `.gob` dosyası oluşturmanın uzun vadeli riskleri (startup süresi, cloud sync verimsizliği, dosya handle limitleri) belgelendi. |
| **Hata Yönetimi** | Flutter event sistemi devre dışı olduğu için arka plan hatalarının (Cloud Sync, Embedding, Installer) UI'a ulaşmadığı **kritik** olarak işaretlendi. |
| **Güvenlik** | Yeni `🔐 Security & Privacy` bölümü eklendi: temp dosya sızıntısı riski ve `0.0.0.0` bind tehlikesi belgelendi. |
| **Donanım** | Windows'ta hardcoded ses cihazı GUID sorunu ve Docker/container ortamlarında GPU algılama kırılması eklendi. |

*   **Dio import eksikliği:** `models_provider.dart` dosyasında eksik olan `dio` import'u eklendi — derleme hatası giderildi.

## ⚡ V1.5.0 → V2.0.0 Geçiş Özeti

| Özellik | V1.5.0 | V2.0.0 |
|---------|--------|--------|
| Motor Dağıtımı | Download-on-demand | **Bundled (Tak-Çalıştır)** |
| İlk Çalıştırma | İnternet gerekli | **%100 Offline** |
| GPU Modu | Otomatik algılama + fallback | **UI'dan seçilebilir** (Auto/CPU/NVIDIA/AMD) |
| Model Yükleme | Asenkron (sessiz hata) | **Senkron (güvenilir yanıt)** |
| Binary Çözümleme | `data/bin/` tek yol | **Akıllı çoklu yol tarama** |
| Paket Boyutu | ~100 MB | **~700 MB – 1 GB** |
| Config API | Yok | **GET/PUT /api/models/config** |
| Motor Modu Kalıcılığı | `.force_cpu` dosyası | **config.yaml → engine_mode** |
| Embedding Timeout | 60 saniye | **120 saniye** |
| Hata Mesajları | İngilizce / teknik | **Türkçe / kullanıcı dostu** |
