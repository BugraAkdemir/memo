# v3.1.0 — Hafıza, WhatsApp, Mobil Uygulama ve Uzaktan Erişim

## Öne Çıkanlar

- **SQLite + sqlite-vec** chromem-go'nun yerini aldı (vec0 ANN index ile vektör arama)
- **Cross-mode**: harici API provider ile sohbet + yerel embedding modeli bağımsız çalışır
- **WhatsApp entegrasyonu** — QR eşleştirme, çift yönlü mesajlaşma, kişi adı çözümleme, beyaz liste dosya aktarımı
- **Mobil uygulama** — Android/iOS için ince Flutter istemci, LAN/ngrok üzerinden Memo backend'e bağlanır
- **Uzaktan erişim** — ngrok tünel desteği, backend'e her yerden erişim
- **Yedekleme/Restore (.memo)** — zip tabanlı tam veri dışa/içe aktarma ve silme
- **Windows desteği** — 8 uyumluluk düzeltmesi, Inno Setup installer
- **Hafıza hata düzeltmeleri** — dosya boyutları artık doğru gösteriliyor, sabit yazılmış Türkçe string'ler L10n ile değiştirildi, fire-and-forget çağrılar düzeltildi

## 🔥 Yeni Özellikler

### Mobil Uygulama (`mobile/`)
- **Tamamen ayrı Flutter projesi** — Android, iOS, Linux, macOS, Windows ve Web hedefleri
- **ConnectScreen** — LAN IP veya remote URL ile Memo backend'e bağlanma, isteğe bağlı `X-Memo-Token` kimlik doğrulama, yerel/uzak geçişi
- **ChatScreen** — SSE akış desteği, Markdown işleme, oturum çekmecesi, yazıyor göstergesi
- **SettingsScreen** — 3 sekme: Genel (backend URL, token), Sağlayıcılar (görüntüle/aç/kapat/sil), Modeller (listele, başlat, durdur)
- `/model` komutu ile çalışma zamanında model değiştirme
- Riverpod durum yönetimi, Material 3 tema
- **Tüm AI işlemleri masaüstünde kalır** — mobil sadece uzak görüntüleme katmanı
- *Gelecek: RAG, WhatsApp, Orkestra, Ajan, bulut senkronizasyonu, yedekleme mobilde*

### Uzaktan Erişim (ngrok)
- `internal/ngrok/` — `installer.go`, `manager.go`, `ngrok.go`
- Otomatik ngrok binary indirme ve tünel yönetimi
- Yapılandırılabilir domain, bölge ve port yönlendirme
- Yerel kurulumla yan yana çalışır, yerel/uzak arasında geçiş yapılabilir
- Orkestra başlatma, ngrok farkındalığı ile yeniden düzenlendi

### WhatsApp Entegrasyonu
- WhatsApp Web QR eşleştirme (`internal/whatsapp/`)
- Yerel izole SQLite mesaj deposu (ana veritabanından bağımsız)
- Kişi adı çözümleme (`resolveDisplayName()`): rehber senkronizasyonu, push isimleri, telefon numarasına düşme
- `importContacts()` — whatsmeow'dan tüm rehberi startup'ta içe aktarır
- Çift yönlü mesajlaşma (`SendMessage()`, `handleMessage`, `handleHistorySync`)
- **Beyaz liste tabanlı dosya aktarımı:** güvenilir kişiler beyaz listedeki dizinlerden dosya isteyebilir; otomatik yetkilendirme
- Agent araç seti: `SendWhatsApp`, `SearchWhatsApp`, `LatestWhatsAppChats`, `GetWhatsAppMessages`
- Ayrı WhatsApp sohbet modu (izole executor + tool kaydı)
- `waToolAdapter` ile `tools.WhatsAppClient` interface uyarlaması
- Endpoint'ler: `POST /api/whatsapp/chat-stream`, `GET/POST /api/whatsapp/chat-mode`
- Frontend: QR gösterimi (`qr_flutter`), chat toggle, ayrı WhatsApp ekranı
- `importContacts` nil pointer fix: `Store.Contacts` nil kontrolü eklendi

### Yedekleme / Geri Yükleme (.memo)
- `GET /api/export` — zip olarak tüm verileri dışa aktar
- `POST /api/import` — zip'ten geri yükle
- Kapsam: `sessions/`, `config/config.yaml`, `providers.json`, `orchestra.json`, `memory/`, `whatsapp/`
- Modeller opsiyonel (`?include_models=true`)
- **Tüm Verileri Sil:** `POST /api/wipe` — çift onaylı tam silme
- Frontend: `_BackupRestoreTab` (Export/Import/Wipe butonları, "Modelleri dahil et" toggle)
- **Export bug fix:** `filepath.Rel(src, path)` düzeltildi (çift iç içe zip hatası)
- **Import bug fix:** Sabit `data/` öneki kaldırıldı, doğru path mapping

### SQLite + sqlite-vec Vektör Deposu
- `internal/database/sqlite.go` — WAL modu, write-queue, havuz yönetimi
- `internal/database/vec_register.go` — özel sürücü + vec0 extension yükleyici
- `internal/memory/store.go` — `SaveInteraction`, `RetrieveContext` (vec0 ANN + Go fallback)
- `internal/memory/embedder.go` — chromem-go bağımlılığı tamamen koptu
- ANN arama: `CREATE VIRTUAL TABLE vec_memories USING vec0(embedding FLOAT[...])`
- vec0 yoksa Go brute-force cosine similarity fallback
- Memory store goroutine'de başlar (HTTP sunucusunu engellemez)

### Cross-Mode (API + Local Embedding)
- `memory.embedding_model_repo` ve `memory.embedding_model_file` config alanları
- Startup'ta embedding model'i otomatik indir + başlat
- API provider chat'te, local model embedding'de çalışır
- Embedding sunucusu (`:8082`) provider değişikliklerinden etkilenmez
- `embedding_auto_start: false` varsayılan

### Windows Desteği (8 Uyumluluk Düzeltmesi)
- **Komut çalıştırma**: Linux'ta `bash -c`, Windows'ta `cmd /C`
- **Sinyal yönetimi**: `syscall.SIGTERM` sadece Linux/macOS
- **Korumalı dizinler**: Windows yol koruması
- **Ses kaydı durdurma**: `Process.Kill()` fallback
- **Makine anahtarı**: Windows `MachineGuid` registry
- **GPU algılama**: Windows nvidia-smi yolu
- **Sembolik link**: Windows'ta kopyalama fallback
- **Cross-volume rename**: copy+delete fallback

### Windows vec0.dll
- sqlite-vec v0.1.9 Windows DLL (283 KB) `binaries/windows/` altında
- vec0.dll yoksa Go fallback modunda çalışır

## 📝 Notlar

- **Migration**: Eski `.gob` anılar sıfırdan başlanıyor (migration script isteğe bağlı)
- **CGO zorunlu**: `CGO_ENABLED=1 go build/test/run` (Windows'ta MinGW GCC gerekli)
- **vec0.so/vec0.dll**: Otomatik yüklenir, yoksa Go brute-force fallback kullanılır
- **Embedding model default**: `nomic-ai/nomic-embed-text-v1.5-GGUF` (768 dim)
- **WhatsApp**: whatsmeow multi-device API, oturum `data/whatsapp/` altında saklanır
- **WhatsApp mesajları**: Ana bellekten bağımsız, ayrı SQLite veritabanında
- **Mobil**: Sadece ince istemci; tüm AI/ML işlemleri masaüstü backend'de kalır
- **Yedek formatı**: `.memo` = ZIP, açık standart, manuel olarak da incelenebilir
- **Lisans**: GNU AGPL v3 (MIT değil)
