# Memo v3.1.0 — What's New

> A major release: redesigned interface, smarter model discovery, WhatsApp integration, mobile companion, and much more.

---

## The Big Picture

This release focuses on two things above all else: **making Memo feel polished and easy to use**, and **making local AI actually work well** — without needing to be a developer to figure it out.

---

## New Look

### Interface Redesigned From Scratch
The entire desktop UI has been rebuilt. The layout, colors, typography, and spacing have all been rethought from the ground up. Everything is cleaner, more intentional, and easier to navigate.

### "Pewter Study" Dark Theme
A new default dark theme that's easier on the eyes during long sessions — warm neutrals, clear contrast, no harsh whites.

---

## Model Store — Completely Rebuilt

The model discovery and download experience has been completely redesigned to work like LM Studio.

### Two-Panel Layout
The Model Store is now split into two panels: a model list on the left, and a rich detail view on the right. No more scrolling through walls of text to find what you need.

### Model Logos
Each model in the list now shows the real logo of the company that made it — Google, Microsoft, Qwen/Alibaba, nomic, and others. The logo is fetched automatically from HuggingFace.

### Only Official Models in "Recommended"
The curated model list now exclusively shows models published by the original creators — not third-party re-uploads or community forks. You'll see:
- **Gemma 3 4B & 12B** — Google's official GGUF release
- **Qwen 3 8B** — Qwen's latest model (official)
- **Qwen 2.5 7B, 14B, Coder 7B** — Qwen official releases
- **Phi-3 mini** — Microsoft official
- **Nomic Embed v1.5** — for memory/RAG

### Download Options That Make Sense
Instead of raw file names like `Q4_K_M`, download options now show plain-language quality labels:
- **Balanced quality** — best for most computers
- **High quality** — if you have more RAM/VRAM
- **Smallest size** — for tight hardware

### Hardware Fit Badges
Every download option shows whether it will run well on your machine:
- **✓ Fits** — will run fast
- **~ CPU OK** — will run, but slower (CPU offload)
- **× Too large** — may not fit in memory

### Filter & Sort
Find what you need faster with filters for model size (1–8B, 8–14B, 14B+) and capability (Tools, Vision, Code), plus sorting by download count or model size.

### Capability Tags
Each model shows icons for what it can do:
- 🔧 **Tool Use** — can use Agent mode and run tasks
- 👁 **Vision** — can understand images
- `</>` **Code** — specialized for programming

### README & Author Info
The detail panel shows the model's full README from HuggingFace, plus a "More from this author" section so you can explore related models.

---

## Agent Mode

### Stable Tool Use with Local Models
Agent mode (where Memo can browse files, run commands, write code, and take actions autonomously) now works reliably with local models. Memo automatically detects whether a loaded model supports tool calling — from the model's HuggingFace metadata, or by recognizing the model family.

---

## WhatsApp Integration

Connect Memo to your WhatsApp account and let the AI assist with your conversations.

- **QR pairing** — scan a code to link your WhatsApp, no phone access required
- **Read & reply** — Memo can search your messages and send replies
- **AI assistant in WhatsApp** — ask the AI to draft a response or summarize a thread
- **File sharing** — trusted contacts can request files; Memo checks a whitelist before sharing
- **Dedicated WhatsApp mode** — a separate chat interface just for WhatsApp conversations

---

## Mobile Companion App

A thin mobile app (Android & iOS) that connects to Memo running on your desktop.

- Type and read messages from your phone while AI processing stays on your desktop
- Connect over local Wi-Fi or remotely via a tunnel
- Optional access token for security

---

## Remote Access

Access your Memo instance from anywhere with built-in ngrok tunnel support. Start a tunnel from Settings and get a public URL — no port forwarding or IT knowledge required.

---

## Memory Improvements

- **Vector search rebuilt** with SQLite + sqlite-vec for faster, more reliable memory retrieval
- **Cross-mode support**: use a cloud AI for chat while a local model handles memory embedding independently
- **File sizes** in memory now display correctly (was showing 0 KB before)
- **Embedding model** auto-starts on launch if configured — memory just works

---

## Backup & Restore

Export everything — sessions, memory, settings, models — as a single `.memo` file. Restore it on any machine. Works as a manual backup or when migrating to a new computer.

---

## Windows Support

Memo now runs natively on Windows with full feature parity. GPU detection, model downloads, agent tools, and the embedding model all work on Windows.

---

## Setup Wizard

New first-run experience with step-by-step setup: choose a theme, language, and assistant personality from presets (Casual, Formal, Technical, Creative, Fun, Buddy — or write your own prompt).

---

## Bug Fixes & Polish

- Memory settings UI: await/error handling fixed — operations no longer silently fail
- WhatsApp contact list: nil pointer crash on first connect fixed
- Archive export: nested zip path bug fixed
- Embedding server: port conflict detection added
- Turkish and English UI strings harmonized throughout
