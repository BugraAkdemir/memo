# v3.1.0 — SQLite + sqlite-vec Göçü, Cross-Mode ve Windows Desteği

## Öne Çıkanlar

- **chromem-go tamamen kaldırıldı**, yerine **SQLite + sqlite-vec (vec0 ANN index)** geldi
- **Cross-mode**: API provider ile chat + local embedding model aynı anda çalışabiliyor
- Vektör arama artık **Vamana grafik algoritması** ile O(log n) — bellek büyüse de hız düşmüyor
- **Windows desteği eklendi** — 8 farklı uyumluluk sorunu çözüldü
- Tüm dökümantasyon güncellendi (~50 dosya)

---

## 🔥 Yeni Özellikler

### SQLite + sqlite-vec Vektör Deposu
- `internal/database/sqlite.go` — WAL modu, write-queue, pool yönetimi
- `internal/database/vec_register.go` — sqlite-vec loadable extension otomatik yükleme
- `internal/memory/store.go` — `SaveInteraction`, `RetrieveContext` (vec0 ANN + Go fallback)
- `internal/memory/embedder.go` — chromem-go bağımlılığı tamamen koptu
- ANN index ile arama: `CREATE VIRTUAL TABLE vec_memories USING vec0(embedding FLOAT[...])`
- vec0 yoksa Go'da brute-force cosine similarity fallback

### Cross-Mode (API + Local Embedding)
- `memory.embedding_model_repo` ve `memory.embedding_model_file` config eklendi
- Startup'ta embedding model'i otomatik indir + başlat
- API provider chat'te, local model embedding'de çalışıyor
- Embedding server (`:8082`) provider switch'ten etkilenmiyor

### Windows Desteği (8 Uyumluluk Düzeltmesi)
- **Komut çalıştırma** (`internal/agent/tools/command.go`): Linux'ta `bash -c`, Windows'ta `cmd /C` kullanılıyor; PATH Windows'a göre ayarlanıyor
- **Sinyal yönetimi** (`main.go`): `syscall.SIGTERM` sadece Linux/macOS'te dinleniyor, Windows'ta sadece `os.Interrupt` (Ctrl+C) kullanılıyor
- **Korumalı dizinler** (`internal/agent/sandbox.go`): Windows'ta `C:\Windows\`, `C:\Program Files\` gibi yollar korunuyor
- **Ses kaydı durdurma** (`app.go`): Windows'ta `os.Interrupt` gönderilemediği için `Process.Kill()` fallback'i kullanılıyor
- **Makine anahtarı** (`internal/provider/config.go`): Windows'ta `MachineGuid` registry'den PowerShell ile okunuyor; macOS'ta `IOPlatformUUID` ile fallback
- **GPU algılama** (`internal/llama/gpu.go`): `nvidia-smi` Windows'ta `C:\Program Files\NVIDIA Corporation\NVSMI\` içinde aranıyor
- **Sembolik link** (`internal/llama/installer.go`): Windows'ta symlink yerine dosya kopyalanıyor (admin/Developer Mode gerektirmez)
- **Cross-volume rename** (`app.go`, `internal/modelstore/modelstore.go`): `os.Rename` başarısız olursa (farklı disk/partition) copy+delete ile fallback

### Windows vec0.dll
- sqlite-vec v0.1.9 Windows DLL (283 KB) `binaries/windows/` altına eklendi
- CPU, NVIDIA, AMD alt dizinlerinde de mevcut
- vec0.dll yoksa Go fallback modunda çalışıyor

## 🪟 Windows Build

Windows'ta build almak için:

### Gereksinimler
- Go 1.25+ (https://go.dev/dl/)
- Git (https://git-scm.com/download/win)
- GCC (MinGW-w64): https://www.mingw-w64.org/ veya `choco install mingw`
- Flutter 3.10+ (sadece frontend build için): https://docs.flutter.dev/get-started/install/windows

### Build Adımları

```batch
REM Yalnızca backend (öncelikle test et)
set CGO_ENABLED=1
go build -o memo.exe .

REM Tüm backend testleri
go test ./...

REM Frontend dahil tam paket (Flutter yüklüyse)
cd frontend
flutter build windows --release
cd ..
.\build_releases.bat
```

> **Not**: `build_releases.sh` Linux için yazıldı. Windows'ta manuel adımlar:
> 1. `go build -o memo.exe .`
> 2. `binaries/windows/vec0.dll` binary yanına kopyala
> 3. Frontend için `flutter build windows --release` çalıştır
