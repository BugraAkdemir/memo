# v3.1.0 — SQLite + sqlite-vec Göçü, Cross-Mode, WhatsApp ve Yedekleme

## Öne Çıkanlar

- **chromem-go tamamen kaldırıldı**, yerine **SQLite + sqlite-vec (vec0 ANN index)** geldi
- **Cross-mode**: API provider ile chat + local embedding model aynı anda çalışabiliyor
- **WhatsApp entegrasyonu** — QR eşleştirme, mesajlaşma, kişi adı çözümleme, beyaz liste dosya aktarımı
- **Yedekleme/Restore (.memo)** — zip tabanlı tam veri aktarımı
- **Windows desteği** — 8 uyumluluk sorunu çözüldü, Inno Setup installer
- Vektör arama artık **Vamana grafik algoritması** ile O(log n)
- Tüm dökümantasyon güncellendi

---

## 🔥 Yeni Özellikler

### WhatsApp Entegrasyonu
- WhatsApp Web QR eşleştirme (`internal/whatsapp/`)
- Yerel mesaj deposu (izole SQLite, ana bellekten bağımsız)
- Kişi adı çözümleme (rehber senkronizasyonu + push isimleri, `resolveDisplayName()`)
- `importContacts()` — startup'ta whatsmeow'dan tüm rehberi alır (214 kişi)
- Çift yönlü mesajlaşma (`SendMessage()`, `handleMessage`, `handleHistorySync`)
- **Beyaz liste tabanlı dosya aktarımı:** güvenilir kişilerden dosya talebi + beyaz listedeki dizinlerden otomatik gönderme
- Agent araçları: `SendWhatsApp`, `SearchWhatsApp`, `LatestWhatsAppChats`, `GetWhatsAppMessages`
- Ayrı WhatsApp sohbet modu (izole executor + tool kaydı, `whatsAppChatMode`)
- `waToolAdapter` ile `tools.WhatsAppClient` interface uyarlaması
- `POST /api/whatsapp/chat-stream` + `GET/POST /api/whatsapp/chat-mode` endpoint'leri
- Frontend: QR gösterimi (`qr_flutter`), chat toggle, ayrı WhatsApp ekranı
- `importContacts` nil pointer fix: `Store.Contacts` nil kontrolü eklendi

### Yedekleme / Geri Yükleme (.memo)
- `GET /api/export` — zip olarak tüm verileri dışa aktar
- `POST /api/import` — zip'ten geri yükle
- Kapsam: `sessions/`, `config/config.yaml`, `providers.json`, `orchestra.json`, `memory/`, `whatsapp/`
- Modeller opsiyonel (`?include_models=true`)
- **Wipe All Data:** `POST /api/wipe` — çift onaylı tüm verileri silme
- Frontend: `_BackupRestoreTab` (Export/Import/Wipe butonları, "Modelleri dahil et" toggle)
- **Export bug fix:** `filepath.Rel(src, path)` düzeltildi (çift iç içe zip hatası)
- **Import bug fix:** Sabit `data/` öneki kaldırıldı, doğru path mapping ile çıkartma

### SQLite + sqlite-vec Vektör Deposu
- `internal/database/sqlite.go` — WAL modu, write-queue, pool yönetimi
- `internal/database/vec_register.go` — sqlite-vec loadable extension otomatik yükleme
- `internal/memory/store.go` — `SaveInteraction`, `RetrieveContext` (vec0 ANN + Go fallback)
- `internal/memory/embedder.go` — chromem-go bağımlılığı tamamen koptu
- ANN index ile arama: `CREATE VIRTUAL TABLE vec_memories USING vec0(embedding FLOAT[...])`
- vec0 yoksa Go'da brute-force cosine similarity fallback
- Memory store goroutine'de başlar (HTTP server'ı bloklamaz)

### Cross-Mode (API + Local Embedding)
- `memory.embedding_model_repo` ve `memory.embedding_model_file` config eklendi
- Startup'ta embedding model'i otomatik indir + başlat
- API provider chat'te, local model embedding'de çalışıyor
- Embedding server (`:8082`) provider switch'ten etkilenmiyor
- `embedding_auto_start: false` varsayılan

### Windows Desteği (8 Uyumluluk Düzeltmesi)
- **Komut çalıştırma** (`internal/agent/tools/command.go`): Linux'ta `bash -c`, Windows'ta `cmd /C`
- **Sinyal yönetimi** (`main.go`): `syscall.SIGTERM` sadece Linux/macOS
- **Korumalı dizinler** (`internal/agent/sandbox.go`): Windows yol koruması
- **Ses kaydı durdurma** (`app.go`): `Process.Kill()` fallback
- **Makine anahtarı** (`internal/provider/config.go`): Windows `MachineGuid` registry
- **GPU algılama** (`internal/llama/gpu.go`): Windows nvidia-smi path
- **Sembolik link** (`internal/llama/installer.go`): Windows'ta kopyalama fallback
- **Cross-volume rename** (`app.go`, `internal/modelstore`): copy+delete fallback

### Windows vec0.dll
- sqlite-vec v0.1.9 Windows DLL (283 KB) `binaries/windows/` altında
- vec0.dll yoksa Go fallback modunda çalışır

## 📝 Notlar

- **Migration**: Eski `.gob` anılar sıfırdan başlanıyor (migration script isteğe bağlı)
- **CGO zorunlu**: `CGO_ENABLED=1 go build/test/run` (Windows'ta MinGW GCC gerekli)
- **vec0.so/vec0.dll**: Otomatik yüklenir, yoksa Go fallback kullanılır
- **Embedding model default**: `nomic-ai/nomic-embed-text-v1.5-GGUF` (768 dim)
- **WhatsApp**: whatsmeow multi-device API, session `data/whatsapp/` altında saklanır
- **WhatsApp mesajları**: Ana bellekten bağımsız, ayrı SQLite veritabanında
- **Yedek formatı**: `.memo` = ZIP, açık standart, manuel olarak da incelenebilir
- **Lisans**: GNU AGPL v3 (MIT değil)
