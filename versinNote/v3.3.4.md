> **In Development** · Not yet released

## Fixed: A New Chat Message Could Queue Behind Background Memory Work

On a local model (which processes one request at a time), sending a message right after Memo finished quietly extracting a fact from your previous turn could leave that new message waiting in line behind it instead of starting right away — a small but real delay that only affected local-model setups. A real chat message now cancels any in-flight background memory call before it's sent, so background bookkeeping never holds up an actual conversation.

## Fixed: Windows Installs Could Fail to Launch With a Missing `msvcp140.dll` Error

A clean Windows machine without the Visual C++ Runtime already installed (common on fresh VMs and some new PCs) couldn't start Memo at all. The installer now bundles the Visual C++ Redistributable and installs it silently, with no extra step needed from the user.
