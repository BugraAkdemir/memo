# Memo v4.1.0 — Release Notes

> August 25, 2026 · [Download](https://memo.bugradev.com)
> Memo's agent can now reach files outside its own project folder — with your permission, every time.

---

## Big Feature: Files From Anywhere, Not Just Memo's Folder

`share_file` shipped just before this release, letting Memo send a file or folder straight through WhatsApp, Telegram, or the chat itself. In practice it ran into a wall immediately: the agent's sandbox was fixed to Memo's own install/project directory the moment it started, so it could hand you a file it had created, but not one already sitting on your Desktop — the single most common thing people actually asked for.

Memo now has a `change_directory` tool that lets the agent widen its own working directory, mid-conversation, to somewhere else you point it at — a temp folder, a sibling project, your Desktop. It's gated exactly like any other sensitive action: a permission prompt (or instant, if you've turned on auto-approve) shows exactly where it wants to switch to, before it touches anything there. And it doesn't wait to be told the magic phrase — if a file request fails because it's outside the current folder, Memo now recognizes that itself and offers to switch, instead of asking you to go move the file into its folder by hand.

This works the same way everywhere: the desktop app, WhatsApp, and Telegram all share the identical permission flow, so a directory switch asked for over Telegram gets the same yes/no confirmation a desktop prompt would show.

## Also in this release

- **Backend replies now fully respect your language setting.** Chat error messages, agent tool results, and the local-model installer's progress/error text used to come back in Turkish regardless of what the UI was set to — a long-standing seam between the Flutter UI's language toggle and the Go backend's own strings. All of it now routes through the same `Identity.UILanguage` setting the rest of the app already honors.
- **Memo knows it's reachable over WhatsApp and Telegram**, not just the desktop chat — its own sense of identity now reflects that, which is what makes it think to offer sending a file through whichever channel you're actually talking to it on.
- **Internal housekeeping:** CI now enforces the project's zero-hardcoded-string rule automatically instead of relying on catching it in review, and rejects any commit carrying AI-attribution text.

## What's next

Web search is getting a real rework — moving off a single scraped search engine onto a proper multi-engine library with actual page-content fetching, not just link snippets. It's built and tested on its own branch; landing it on `main` is next up.
