# Memo v4.6.0 — Release Notes

> September 2026 · [Download](https://memo.bugradev.com)
> Memo can now open apps and your browser for you, just by asking. Memory settings got rebuilt end to end — see, edit, and selectively delete exactly what Memo remembers — and a new free-friendly provider (Cline) joins a redesigned Add Provider flow built around finding a $0 model in one click.

---

## Big Feature: Memo can open apps for you

Ask Memo to open something — "Spotify'ı aç", "Steam'i başlat", "tarayıcıyı aç" — and it now actually launches it, on Windows, macOS, and Linux alike. This is the first layer of a longer computer-use roadmap: today it's launching a named desktop app or your default browser; controlling what happens inside that app (playing a specific song, opening a specific page) is a separate, future step.

"Browser" and its common Turkish/English variants open a blank tab directly. Any other name is handed to the OS's own way of launching an app by name — the same thing typing it into a terminal would do. Launching an app is a real action with a real side effect, so it goes through Memo's permission system like every other agent tool, just one notch lighter than a shell command.

Care went into making sure Memo doesn't reach for this by mistake: a question like "en son haberler ne" should trigger a web search, not open a browser, and the tool descriptions Memo reads are written specifically to keep that boundary clear.

## Big Feature: Memory settings, rebuilt

The Memory tab in Settings could tell you *how* memory retrieval was configured, but not *what* Memo actually remembers — and there was no way to fix a wrong memory without clearing everything. This release closes both gaps:

- **See what Memo knows about you.** A new, always-visible list shows every fact Memo has pinned about you — read-only, for peace of mind, not fed back into any prompt beyond what already happens automatically.
- **Edit or delete exactly what's wrong**, one fact at a time or several at once, with checkboxes and a select-all/deselect-all bar. A separate, identically-equipped list handles your ordinary (non-pinned) conversation history — keep your pinned facts while clearing chat history, or the reverse, entirely independently. Every delete — one row or a whole selection — asks for confirmation first and shows exactly how many records it removed.
- **A properly organized tab instead of one long scroll.** Retrieval settings, memory files, usage analytics, known facts, conversation history, and debug search used to stack on top of each other in a single page — reaching the last section meant scrolling past everything else. They're now five focused sections switched with a pill bar at the top, each showing a live count before you even open it. The General settings tab got the same treatment, split into General, Features, Reset, and CLI & Uninstall.
- **Dream — the background pass that compresses old, related pinned facts into cleaner summaries — actually runs now.** It quietly wasn't: a wiring gap left it permanently dormant on a fresh launch unless you happened to trigger an unrelated action first, with no indication in the UI that anything was wrong. Fixed at the source; Dream now activates the moment Memo starts.

## New Feature: Cline joins as a provider, and Add Provider gets easier to navigate

**Cline** is now a supported external LLM provider — same one-click setup as every other provider, its own logo in the picker, and (like OpenRouter/Kilo/OpenCode Zen) a real per-model free/paid catalog instead of a bare model-ID list.

The bigger change is to Add Provider itself: with fourteen options in a flat list, there was previously no signal at all about which ones cost nothing to try. Providers with a genuine free tier now show a green badge and sit in their own group, separate from paid providers — and for the four providers with a real free-model catalog, a new **"Select Free Model"** button picks a working $0 model for you in one click, no understanding of pricing or model-ID syntax required.

## Small feature: see which other chats are still working

Running several conversations at once — a task in the background, a WhatsApp or Telegram reply, a second browser tab open to the same Memo — used to leave the sidebar showing nothing for any chat you weren't actively looking at, even while it was still generating a reply. Every chat that's actually working now shows the same small spinner (and a "just finished" indicator right after) the sidebar already used for Claude Code/Codex sessions — extended to cover every kind of chat, not just those.

## Reliability pass

- **Memo no longer goes completely silent on a turn.** A model that produces no tool call and no text — a weak or local model, a request nothing in the current tool set fits — used to end the turn with literally nothing shown, indistinguishable from a dropped request. It now always leaves you with a real, visible message instead of dead air.
- **Telegram and WhatsApp now correctly prefer what you just told Memo over an old conversation summary.** Long-running chats on those channels occasionally condense their oldest messages into a background summary for context-budget reasons — accurate for what was true *at the time*, but with no signal telling the model which one wins if it conflicts with a fact you pinned since. Memo's prompt now says so explicitly.
- A handful of Settings screens (API Providers, Backup & Restore, Learning, Usage Stats, and Memory's own selection toolbar) had a title or label that could crowd against a button under long Turkish text at narrow window widths — audited and fixed across the board.

## Security

- A transitive dependency (`google.golang.org/grpc`, pulled in indirectly through cloud/auth libraries — nothing in Memo calls it directly) carried a flagged HTTP/2 memory-exhaustion vulnerability (GO-2026-6348). Bumped to the patched version; nothing else changed.
