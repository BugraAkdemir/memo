# Memo v4.7.0 — Release Notes

> October 17, 2026 · [Download](https://memocpp.com)
> Memo can now update itself: open it, see what's new, click **Update now**, and it downloads, checks, installs and restarts — no website. The engines that run your local models (llama.cpp, whisper.cpp, the Subscriptions connector) can be refreshed on their own, without waiting for a new Memo. Also in this release: ChatGPT and claude.ai as an experimental **Beta** provider that uses your own signed-in browser window, and a round of work that makes Memo write code better and spend fewer tokens doing it.

---

## Big Feature: Update from inside Memo

When Memo starts it checks whether a newer version exists. If it does, a window shows the versions, the download size and a short note about what you gain.

- **One click.** *Update now* downloads the release, verifies it, closes Memo, swaps the new files in and opens Memo again. On Windows it downloads the installer, checks it and starts it (you approve the normal Windows prompt and finish in the installer).
- **Your things are never touched.** Settings, models, memory, chats and provider keys stay exactly where they are — only the program files are replaced.
- **If the new version doesn't start, you get the old one back.** Memo waits for the new version to answer; if it doesn't, the previous files are restored and the previous version is opened again. The next time you open the update window it tells you the attempt failed and why, and lets you try again.
- **You stay in control.** *Later* asks again next launch. *Skip this version* is remembered (a newer release still asks). A release marked **required** hides *Skip*, but *Later* is always there.
- **Installs that can't update themselves** (AppImage, packages, Docker, running from source) are told a new version exists and get an *Open download page* button instead.
- **Safe by construction.** Every download is checked against a manifest signed by the Memo maintainer; a file that doesn't match is deleted and nothing is installed. A website or storage account that was taken over could withhold an update, but could not make Memo install a file that wasn't signed.

## New Feature: Engine updates without a new Memo

The programs that run your local models can now be updated separately.

- When a newer **llama.cpp**, **whisper.cpp** (speech-to-text) or **Subscriptions connector** is published, Memo offers it in its own window. Applying it briefly stops the running local model, installs the new engine, checks that it really is the build it claims to be, and loads your model again.
- New engine files go into Memo's data folder, never over the installed program, so this works the same on Windows without administrator rights. If the new engine doesn't work, it is removed and the one that shipped with Memo is used again.
- Memo only offers an engine update for the engine it actually uses on your machine, and never switches you to a different engine flavour.

## Beta Feature: ChatGPT and claude.ai through your own browser window

> **Beta.** Off by default. Turn it on under **Settings › Beta Features**; a notice must be accepted before anything runs.

Instead of spending API quota, you can add **ChatGPT** or **claude.ai** as a provider. Memo opens a real, visible browser window with its own profile, you sign in yourself, and each message is typed into that page. Text only (no tools). Memo never sends background work (titles, memory, routing) to a web chat, and a sign-in or human check is always yours to do.

Not yet tried against a signed-in account — treat it as experimental.

## Improvements: writing code, and what it costs

- **Memo can search inside files.** A new content-search tool finds code by what it says, not only by file name.
- **Code Mode is leaner.** It stops sending tools that have nothing to do with coding (messaging, calendar, routines…) and uses a coding-focused prompt, so more of the context window and the bill goes to your project.
- **Longer answers where the model allows it.** Claude replies are no longer capped at a fixed 4096 tokens; the limit now follows the model family.
- **Cheaper repeated turns.** The memory block no longer changes the start of every prompt, and Claude tool turns keep a rolling cache point, so providers can reuse more of the conversation at the cached price.
- Plain chat's "keep it short" style no longer applies when you ask for code.

## Fixes

- An OpenCode Zen free-tier refusal is now explained in plain words instead of a generic 403.
- Settings › Web chat is hidden entirely while Beta Features is off.

## Good to know

- **The first update is manual.** 4.6.0 and earlier have no updater, so moving to 4.7.0 means one last manual update (re-run the install command or installer). Updates after this one are one click.
- **Not yet run on real Windows or macOS machines.** The Linux path was exercised end to end with real processes (successful update, an update that fails and is rolled back); the Windows installer hand-off and macOS are built and tested in CI only. If the in-app update misbehaves there, the download page still works.
- **Engine updates currently reach Linux only.** The Windows and macOS engine folders don't yet record which llama.cpp build they hold, so they are not offered engine updates until that is confirmed.
- **The download is the whole app (about 780 MB) each time.**
