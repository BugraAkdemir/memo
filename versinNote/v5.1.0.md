# Memo v5.1.0 — Release Notes

> November 20, 2026 · [Download](https://memocpp.com)
> Memo v5.1.0 cuts agent prompt overhead by ~90% with **hybrid on-demand tool loading** and a **compact profile** for small local models, overhauls **desktop startup speed and process supervision** across Windows, macOS and Linux, upgrades bundled **llama.cpp (`b12359` / v1.0.0 stable)** and **CLIProxyAPI (`v8.0.79`)** engines, adds automatic **multimodal projector (`mmproj`)** downloads and **GPU-to-CPU fallback**, enables **global skill installation** and **tool-powered Morning Briefings**, and modernizes Settings, the chat composer, and the model picker.

---

## Big Feature: Hybrid On-Demand Tools & Small-Model Compact Profile

- **~90% smaller starting tool schema.** On normal and large context windows (`>= 10k` tokens), Memo now keeps core everyday tools (`read_file`, `list_directory`, `search_content`, `web_search` in chat; plus `search_files`, `write_file`, `edit_file`, `run_command` in Code Mode) pinned from turn 1 while grouping specialized tools (`subagents`, `tasks`, `skills`, `system`, `browser`, `os`) behind `load_tools`. Basic reading, searching and coding happen in zero extra turns, while initial tool-schema overhead drops from ~10.2K tokens to ~1.05K tokens.
- **Unconnected integrations stay out of the prompt.** Tools and system instructions for Mail, WhatsApp, Telegram, Digital Twin and Calendar are automatically omitted whenever those integrations are not connected or have no events.
- **Compact profile for 4k–8k local models.** Models with a context window under 10k tokens automatically run with a compact persona prompt, a 25% reply token reserve, and `load_tools`-only initial tool definitions so a 4k or 8k local model never overflows on the first message. Custom `llama.cpp` providers now auto-detect their real context window via `/props`.
- **Configurable in Settings.** You can toggle **On-demand tool loading** anytime in **Settings → General**.

## Big Improvement: Desktop Lifecycle, Native Tray & Faster Startup

- **Clean process ownership across Windows, macOS and Linux.** Memo now supervises its backend and local engines (`llama-server`, `whisper-server`) through an owned desktop session (`--desktop-session` / `--owned`, Windows Job Objects with `BREAKAWAY_OK`, and Unix process groups). Closing, crashing, or force-killing the desktop app stops its engines cleanly without touching unrelated processes on your machine.
- **Native Windows system tray & recovery.** Memo stays accessible in the Windows system tray, recovers automatically if `explorer.exe` restarts, and falls back to keeping the main window visible with a clear notice if tray registration is unavailable.
- **Faster cold start & offline fonts.** Bundled `Inter` and `SchibstedGrotesk` fonts locally (zero network font fetches at launch), deferred secondary tab building in `AppShell` until first visit, and removed artificial launcher delays on Windows.

## Local Models: Vision Projectors, Smart GPU Selection & Effort Control

- **Automatic `mmproj` download for vision models.** Downloading a vision-capable GGUF model from the Model Store now automatically finds, downloads and associates its matching multimodal projector (`mmproj`) file, and preserves repository filenames for nested downloads.
- **Official hardware-fit recommendations.** The Model Store **Discover** tab highlights official models sized for your machine's RAM and VRAM.
- **Automatic CPU fallback on GPU/Vulkan failure.** If `llama-server` fails to load a model on an integrated or discrete GPU (such as a Vulkan `ErrorDeviceLost` or out-of-VRAM error), Memo automatically retries on the host CPU (`--device none`) instead of failing the turn.
- **Smarter `auto` engine selection.** On Windows, macOS and Linux, `auto` engine mode orders bundled engine flavors (`nvidia`, `amd`, `metal`, `cpu`) by the GPU detected on your machine, including modern Windows DCH driver paths (`%SystemRoot%\System32\nvidia-smi.exe`).
- **Reasoning effort & accurate `t/s`.** The quick **Effort** selector in the chat top bar now works with local `llama.cpp` models as well as custom OpenAI/Anthropic providers. Live and final tokens-per-second (`t/s`) exclude prompt-evaluation (TTFT) latency and count thinking tokens accurately.

## Agent, Skills & Workspace Improvements

- **Agent Mode on by default, with a dedicated workspace.** Agent Mode starts enabled out of the box. Non-project chats use `~/MemoWorkspace` as their default working directory, keeping `working_dir` cleanly separated from registered Project Folders (`project_path`).
- **Install skills globally from anywhere.** You can install skills from GitHub (`owner/repo`) or `npx skills add …` commands in ordinary chats, Telegram and WhatsApp — not only inside a project folder. External Claude Code / Agent Skills with scalar tool lists (`tools: [browser, ...]`) now import cleanly.
- **Calendar as a tool.** Hosted-provider plain chats now access your schedule on demand via `get_calendar_events` whenever your calendar has events, and natural-language dates written with month names reach the calendar intent extractor.
- **Tool-powered Morning Briefing & full-length custom reports.** Morning Briefing custom instructions can now run safe read-only and web tools (`web_search`, `fetch_page`, `read_file` including `@file` mentions, `list_directory`, `search_files`, `search_content`, `run_command_readonly`, `get_calendar_events`) and generate comprehensive multi-paragraph reports (up to 16,000 characters per custom section, removing the old 3-line / 400-character limit).
- **Clearer permission and context messages.** Waiting on a tool permission prompt is now reported as a permission timeout rather than a provider timeout, and local context-window overflows explain how to increase `ctx-size` or compact the chat.

## UI Polish, Subscriptions & Security

- **Refined chat bars, Settings sidebar and model picker.** Reorganized the Settings sidebar from 6 mixed sections into 8 coherent groups and refreshed the About screen (TR/EN). Secondary chat top-bar actions now live in a clean overflow menu, the bottom status strip shows the active model name with a full tooltip, the model picker has softer borders and a search clear button, and the composer hides image/file/microphone buttons when the active model or STT setup does not support them.
- **Bundled engine upgrades.** Upgraded Linux `llama.cpp` (`cpu` + Vulkan plugin, `amd`, `cpu-arm64`) to **`b12359` (`v1.0.0` stable)** and the Subscriptions sidecar (**CLIProxyAPI**) across all four platforms to **`v8.0.79`** (`whisper.cpp` remains at `1.9.5`).
- **Smarter browser fallback (`gosearch/browser v0.4.0`).** Upgraded the optional headless browser engine to `v0.4.0` with unified Markdown readability extraction (`WithMarkdown`), concurrency serialization, instant context cancellation, automatic one-shot crash recovery, and clean graceful shutdown.
- **Leaner system prompt.** Removed the hardcoded developer biography block from every chat turn to save system-prompt tokens.
- **Desktop polish fixes.** Fixed a Turkish text RenderFlex overflow in the local model launch settings dialog (`ModelConfigDialog`), and suppressed benign Linux GTK/GDK XWayland clipboard UTF-8 conversion warning spam that bloated desktop logs.
- **Subscription entitlement awareness.** Models whose subscription allowance or entitlement has ended are hidden from the picker, and active models display an explicit allowance-ended status when exhausted.
- **Strict Minimal Mode & persistent onboarding.** Minimal Mode strictly suppresses background title and tool side-calls while streaming `reasoning_content`. Declining optional setup steps or completing the spotlight tour persists reliably on the backend.
- **KorteksOS Ring-1 integration.** Added the `osbridge` Unix socket client, proactive `korteks-doctor` health ingestion, and a fully localized First-Boot OOBE wizard (`--os-mode`, `--oobe`).
- **Security & toolchain.** Upgraded the Go toolchain across builds and CI to **Go 1.26.11** (`GO-2026-6859`).
